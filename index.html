About Crime Analytics Portal

This web application generates statistical crime analysis based on historical records from 2021 to 2026.

  • Dataset Integration: Synced from indian_crime_data_2021_2026_with_names.csv into browser local storage.
  • Persistent Storage: Newly added records via Officer Dashboard automatically save to browser memory.
  • Interactive Visualization: Dynamic client-side chart generation powered by Chart.js.

About the Crime Map

The map uses the State and City already stored in your crime records.

Your current records contain city-level information rather than exact latitude/longitude coordinates, so markers show the approximate geographic position of the recorded city.
